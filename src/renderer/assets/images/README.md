# Assets de Imágenes

## 📋 Instrucciones para el Logo

### **Dónde colocar tu logo:**
1. Coloca tu archivo PNG en esta carpeta: `src/renderer/assets/images/`
2. Nombra tu archivo como: `logo-farmacias-ms.png`

### **Especificaciones recomendadas:**
- **Formato:** PNG con transparencia
- **Tamaño:** 200x200 píxeles (mínimo)
- **Fondo:** Transparente
- **Resolución:** 72-300 DPI

### **Archivos de logo sugeridos:**
- `logo-farmacias-ms.png` - Logo principal
- `logo-farmacias-ms-small.png` - Logo pequeño (opcional)
- `logo-farmacias-ms-horizontal.png` - Logo horizontal (opcional)

### **Ubicación actual de logos:**
- **Login:** Círculo amarillo con texto
- **Header:** Mismo círculo amarillo
- **Tickets:** Texto "FARMACIAS MS"

### **Una vez que agregues tu logo:**
Los componentes se actualizarán automáticamente para usar la imagen PNG en lugar del círculo amarillo.
